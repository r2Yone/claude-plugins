# Guía de Estilo

## Nombres de variables
- Usar camelCase en JavaScript/TypeScript
- Usar snake_case en Python
- Nombres descriptivos, sin abreviaciones

## Funciones
- Máximo 20 líneas por función
- Una sola responsabilidad por función
- Siempre documentar parámetros y retorno

## Manejo de errores
- Nunca ignorar excepciones con bloques vacíos
- Siempre loggear errores con contexto útil
- Usar tipos de error específicos, no genéricos
